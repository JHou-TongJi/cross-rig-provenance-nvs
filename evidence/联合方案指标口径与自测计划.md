# 联合方案指标口径与自测计划

## 1. 指标原则

当前没有目标车型同步 GT，所以不报告目标视角真实 PSNR/SSIM。所有指标必须写清数据范围、是否使用 GT、是否只统计 geometry、是否包含 visual-only 区域。

## 2. 核心指标

| 指标 | 计算对象 | 口径 |
|---|---|---|
| `camera_success_rate` | 请求的目标相机/帧 | 成功输出 RGB、depth、validity、provenance、report 的比例 |
| `geometry_coverage` | 几何输出 | 有真实结构或受门控结构支持的像素比例 |
| `unknown_rate` | 几何输出 | 无可靠观测、未通过 gate 或目标视野外的比例 |
| `observed_pixels_modified` | 真实观测区域 | 最终 RGB 与 locked input 不同的像素数，目标为 0 |
| `gate_fill_fraction` | geometry hole | 经过 source-target-source 证据筛选后恢复的比例 |
| `generated_fraction` | residual hole | 由生成模型写入的比例，必须单独报告 |
| `depth_lidar_holdout_error` | LiDAR 留出点 | 不参与推理的点投影到深度图后的误差 |
| `reprojection_consistency` | source-target-source | 回投影可见区域的像素/深度残差 |
| `semantic_preservation` | 关键对象/道路结构 | 检测、分割或 DINO 特征的一致性 |
| `temporal_stability` | 连续帧 | 光流/特征轨迹异常、闪烁、目标位姿跳变 |
| `visual_hole_free` | 最终观看图 | 仅表示没有黑洞，不代表真实几何完整 |

## 3. 分组报告

必须单列 `CAM_BACK_RIGHT`、`CAM_FRONT_NARROW`、动态对象、桥下/植被/天空/远景，以及 `5--10 cm`、`10--20 cm`、`20--50 cm` 三档位姿。geometry、gate 和 generated 三类来源也必须分开。

## 4. 自测流程

1. 固定目标 rig、源序列、帧和随机种子；
2. 先跑 l4-se geometry-only，导出深度、validity 和 provenance；
3. 再跑 GCR-NVS T0/DA3 结构链；
4. 再单独打开 gate，记录恢复比例和锁定像素；
5. 最后运行 A-only residual completion，记录 generated mask；
6. 分别计算 geometry 和 visual 指标；
7. 生成源图、目标图、深度、来源、ABS DIFF 和失败案例；
8. 保存命令、commit、配置、模型 hash、设备和耗时。

## 5. 结论写法

> 在无目标车型同步 GT 的条件下，本方案通过 LiDAR 锚点留出、回投影一致性、来源锁定和时序/语义代理指标评价几何可信度；对于完全不可观测区域，单独报告生成比例和视觉质量，不将其宣称为真实观测恢复。
