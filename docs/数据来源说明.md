# 数据来源说明

## 主赛题数据

- 来源：中安智联赛事参考道路采集数据；
- 当前主要开发序列：`2026-05-22-10-25-21`；
- 规模：80 个关键帧，时间跨度约 39 秒，7 路相机和 `LIDAR_CONCAT` 点云；
- 权威索引：每帧 `Key_frames/camera_config/*.json` 的 `sensors` 字段；
- 使用目的：算法开发、无 GT 自测、结果展示和抽样复现；
- 限制：原始数据不随公开代码仓库再分发，最终提交遵守赛事保密要求。

## 第三方模型和代码

Depth Anything 3、Gaussian Splatting、Ultralytics 和 SegFormer 仅作为算法依赖。
具体版本、权重与许可证必须在 `../03_engineering/model_manifest.md` 中登记。

## 数据划分

当前 frame 40 用于最终七相机目标位姿验收；frame 1/10/40/70 用于跨帧代理指标；
其余帧用于时序地图和连续展示。正式报告中必须区分调参样本、验证样本和展示样本。
