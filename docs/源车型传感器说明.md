# 源车型传感器说明

源数据由主办方提供，核心输入包括七路同步或近同步 RGB 图像、LiDAR 点云、每帧 `camera_config.json` 外参/内参以及 `camera_intric.yaml` 畸变参数。

七路相机为：`CAM_BACK_LEFT`、`CAM_FRONT_LEFT`、`CAM_FRONT_RIGHT`、`CAM_BACK_RIGHT`、`CAM_BACK`、`CAM_FRONT_WIDE`、`CAM_FRONT_NARROW`。前五路分辨率为 `1920 x 1080`，前视短焦和长焦为 `3840 x 2160`。原始标定文件已随本目录提供：

- `camera_config.json`：`camera_external`、`fx/fy/cx/cy`、宽高和矩阵存储顺序。
- `camera_intric.yaml`：每路相机的 `K_manual` 与 Brown-Conrady 五参数 `D_manual=[k1,k2,p1,p2,k3]`。

空间转换在去畸变后的针孔域完成，先由 LiDAR 点通过外参进入相机坐标系，再由内参投影到图像；最终展示结果按目标相机 `K` 和 `D` 重新映射回物理畸变域。外参合法性、七相机安装位置、坐标系和 FOV 可视化见 `../04_生成结果/optional_bev_or_projection/`。

主办方数据只提供源车型参考采集，没有目标 L4 小车同步真值图像，因此目标视角不能声称具有真实 PSNR/SSIM GT。评价采用 LiDAR holdout、几何一致性、可见性、来源追踪、时序稳定性和人工视觉审核。
