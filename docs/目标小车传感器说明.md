# 目标 L4 无人物流车传感器说明

当前使用 `target_l4_rig_reference_v1` 作为团队定义的参考目标。完整机器可读配置位于
`../../config/target_l4_rig_v1.yaml`。

## 目标定义

- 车型：L4 低速无人物流车参考原型；
- 车辆尺寸假设：长 5.20 m、宽 2.05 m、高 2.00 m；
- 相机数量：7；
- 输出分辨率：960 x 540；
- 输出帧率：2 FPS，对应关键帧时间间隔；
- 相对源 LiDAR 的整车刚体变化：前移 0.10 m、升高 0.35 m、俯仰 2 度；
- 相机相对安装与去畸变后内参：V1 保留源七相机配置。

目标相机变换为：

```text
T_L_C_target = T_L_R_delta * inverse(T_C_L_source)
T_C_L_target = inverse(T_L_C_target)
```

## 尚待主办方确认

该参数是团队参考假设，不代表主办方官方物流车标定。若主办方提供目标车内外参、
车体原点或地面高度，本配置必须升级版本并重新生成结果，旧指标不能混入新版本。
