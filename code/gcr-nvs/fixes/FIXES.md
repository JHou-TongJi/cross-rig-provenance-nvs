# GCR-NVS 修复计划

## 问题总结
1. PSNR 只有7-8dB（应该15+）
2. hole_psnr = -1.43（空洞区域完全失败）
3. refiner几乎没提升（0.1dB）
4. 损失函数对空洞区域的处理不正确

## 修复优先级

### P0 - 立即修复（影响训练收敛）
1. **损失函数权重修复** - 空洞区域不应该用GT做监督
2. **valid_mask正确性** - 确保只在observed区域计算RGB loss
3. **alpha gate验证** - 确保高置信度区域不被修改

### P1 - 重要修复（提升质量）
4. **几何一致性检查** - 验证投影是否正确
5. **时序ICP质量** - 添加质量门限
6. **训练稳定性** - 学习率调度、梯度裁剪

### P2 - 优化（锦上添花）
7. **数据增强** - 颜色扰动、相机dropout
8. **更好的空洞处理** - 语义引导、边缘约束
